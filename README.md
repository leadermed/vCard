# WP VCard Generator

Generate VCards for contacts and allow users to download them.

## Description

This plugin provides functionality to generate VCards for contacts and allows users to download them. It adds a custom button to the ACF editor interface for employees, allowing users to generate a VCard for each employee and download it. VCards are generated based on the fields configured for each employee.

## Installation

1. Upload the `wp-vcard-generator` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

## Usage

1. After activating the plugin, navigate to the ACF editor interface for employees.
2. You will see a custom button labeled 'Générer une VCARD'. Click on this button to generate a VCard for the respective employee.
3. The generated VCard will be available for download. Users can click on the download link to download the VCard.
4. VCards are generated based on the fields configured for each employee.

## Requirements

- WordPress version: 5.2 or higher
- PHP version: 7.2 or higher
